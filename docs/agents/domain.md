# Domain docs

This repository uses a single-context domain documentation layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant architectural decisions under `docs/adr/` when they exist.
- If these files do not exist, proceed without creating placeholder documentation.

## Vocabulary

Use domain terms defined in `CONTEXT.md` in issue titles, tests, implementation, and documentation. Do not introduce synonyms that conflict with the glossary.

## Architectural decisions

Surface conflicts with an existing ADR explicitly instead of silently overriding the decision.
